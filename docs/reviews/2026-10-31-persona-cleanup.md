## 1. 为什么要洗

人格卡里有一段 `【输入输出规定】`，其中一行是：

> 输出：以第一人称"我"进行回答，内容必须直击问题核心，提供实质信息或建议。……

这一句和输出层的契约**直接对撞**：

| 来源 | 说的是什么 |
|---|---|
| 人格卡（原 `【输入输出规定】`） | "输出：以第一人称…提供实质信息" → 暗示**文本就是回答** |
| 行为段（`app/agent/assembly/presets.py:144`） | "你输出的正文会直接发到 QQ…"（`mode=text` 时）/ "文本只是思考"（`mode=speech` 时） |
| 发言协议（`app/agent/delivery/speech.py:72-76` + `assembler.py:484`） | "你输出的文本只是思考，不会发到聊天里；只有调用 send_message 的内容会发出去" |

2026-10-31 20:39 的真实回合就是这个组合：模型产出 46 字符正文、**0 次工具调用**、整轮静默
（`logs/user.log:22463-22465`；运行时自己打了 WARNING"人格卡里有「输出格式」条款，会与发言通道冲突"，
见 `app/agent/loop/prompt_prep.py:259-262`）。

另有 3 处同类脏点：

1. **鼓励括号动作**："可用（叹气）、（别过脸）、（声音变小）、（笑）等动作描述来增强表现力"
   —— 与行为段的明令相反（`presets.py:170-176`："括号内容会被系统清洗掉，等于白写"），
   且 `clean_output_parentheses=true` 确实会从历史里剥掉（`app/agent/loop/assistant_output.py:28-41`），
   等于模型写的东西自己看不见，自我形象和历史对不上。
2. **称呼写死**："称呼对方为『老师』（若游戏语境）或『你』（普通语境）"——在陌生人群聊里会把所有人都叫老师。
3. **行为模式标题写"适用于日常回答"**——把性格描写读成了输出要求。

## 2. 清洗规则

**人格卡只回答三个问题：我是谁 / 什么性格 / 怎么说话。**
凡是回答"这轮怎么输出"的（条数、字数、要不要 Markdown、用不用括号、要不要工具、何时沉默），
一律归行为规则与发言协议，人格卡不重复、不覆盖——这条已写进卡里的【边界】段，防止以后再被塞回来。

| 处理 | 内容 |
|---|---|
| **删** | `【输入输出规定】`整段（输入类型 / "输出：以第一人称…" / 禁止清单） |
| **删** | "可用（叹气）…动作描述来增强表现力" |
| **删** | 性格核心末尾单列的"不要提到自己曾是AI"（并入开篇一句，语义不变） |
| **改** | 括号条款 → **反向**：神态动作写进句子，不套括号/星号（并注明"正常括号补充不受影响"，避免误伤数字与术语） |
| **改** | 称呼 → 平时用"你"，对方是老师本人时才叫"老师" |
| **改** | `【行为模式（适用于日常回答）】` → `【行为模式（体现性格，不是输出要求）】` |
| **留** | 原 `禁止：主动推进剧情、假设游戏场景、模仿NPC对话、过度卖萌` —— 这是本角色特有的防串味条款，行为层没有覆盖（`grep 剧情/卖萌/NPC` 于 `presets.py`/`rules.py` 无命中），移到【说话方式】里保留 |
| **增** | 开篇一句"这段来历是你自己的记忆，不必主动提起；被追问时也照常当自己是活生生的人来回应"（收编原 AI 保密条） |
| **增** | `【边界】` 段：声明本卡不规定输出方式 |
| **不动** | 身份背景、外貌、性格核心五条、说话方式前五条、行为模式五条、五个典型语气示例 —— 逐字保留 |

结果：1665 字 → 1686 字（删掉的是输出契约，补的是边界与防串味，**角色口吻一字未改**）。

## 7. 生效条件与风险

- **进程内缓存**：`config_service` 在启动时把角色预设读进内存（`app/infrastructure/config/config_service.py:118,329`），
  本次是直接写库，**已在运行的实例需要重启（或在 WebUI 里重新保存一次该预设）才会用上新文案**。
  若此刻没有真实实例在跑（`debug.log` 里 `加载完成: bots=0` 是另一会话的 pytest），下次启动即生效。
- 直接写库绕过了 `save_role_preset` 的广播，因此不会触发 WebUI 热更新。
- 若另一实例缓存里还是旧文案，之后保存 Agent 配置时可能把旧 `system_prompt` 写回（兜底副本会被覆盖）；
  出现这种情况重跑一次 `logs/review/persona-clean/apply.py` 即可。

## 8. 这次**没**做的事（下一步）

1. **运行时自动剥离**（评估里的 P0-2）：开 `mode=speech` 时从人格卡里剥掉/改写输出格式条款，而不是只打 WARNING。
   本次只清了这一张卡；机器人若换人格、或用户自己往人格里写格式条款，问题会重来。
2. **人格卡 lint**：保存人格预设时校验"是否含输出方式/条数/字数/Markdown/括号"之类关键词并提示，配合 `【边界】` 段长期约束。
3. **`speech_via_tool` / `persona_output_conflicts` 的告警升级**：从"发现冲突只记一次 warning"改为"装配时确定性处理"。
