## 统一规范（所有页面必须遵守）

### 结构

- 页面头部统一：
  ```html
  <div class="app-page-header">
    <div>
      <h1 class="app-page-title">标题</h1>
      <div class="app-page-subtitle">一句话说明（≤18 字）</div>
    </div>
    <div class="d-flex gap-2">页面级主操作</div>
  </div>
  ```
  **头部不放状态 chip / 保存状态**；保存状态放内容区第一行（`SaveStatusBar` 已改为：清态什么都不显示，只显示未保存/保存中/失败）。
- 筛选/搜索/批量操作 → `.app-toolbar`；卡片列表 → `.app-card-grid`；并排字段 → `.app-form-grid`。不要再用 `v-row` 手工算 border。
- 只允许一层卡片。表单字段不要再套描边容器（把「卡片 > 描边框 > 输入」压成「卡片 > 字段」）。
- 同一屏内卡片间距统一 16；页面底部补 24 的空白，避免贴边。

### 按钮层级

- 主操作：`color="primary" variant="flat"`；次操作：`tonal`；危险：`tonal color="error"`，或文字链接仅用于行内次级操作。
- 纯图标操作：`variant="text"` + `title` tooltip；不要给图标按钮加 tonal 底色（除非是激活态）。
- 一行最多一个 filled/tonal 强调按钮；同组操作尺寸一致（`size="small"` 或默认，不要混用）。

### 文案（比 UI_COPY.md 更严）

- 删除：设计解释（"为了…"）、元叙述（"这里不再重复入口"、"改动会自动保存"、"日常使用不需要打开"）、口语（"两种都行"、"不用管"）、营销词（"统一查看"、"一站式"、"轻松"）。
- 字段说明只写**做什么/何时用**，≤24 汉字，不用句号结尾也可以。
- 术语：账号（不是机器人/Bot 混用）、功能插件、人格预设、模型服务、会话、上下文。
- 数字带中文单位（30 秒、3 次）；英文只保留 token、LLM、OneBot、MCP、JSON、API Key。
- 不展示：commit/构建戳、消息编号、数据库字段名、裸 snake_case、工具内部 id（如 `get_current_session`）。
- 空态一句话 + 主操作；错误一句话原因 + 重试按钮。

- 390px：无横向滚动；头部操作换行到标题下方；卡片单列；表格可横向滚动但外层不要撑破页面。
