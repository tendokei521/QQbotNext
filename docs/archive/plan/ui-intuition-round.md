# 前端直觉性与配置收敛专项（第六轮）

> 目标：按用户视角修三类问题——**①不符合直觉/解释不清**、**②相似或相同配置多处编辑**、
> **③相似功能没放一起**。数量不限，找完改完，多子 agent 交叉审查验收。

## 0. 方法

1. **只读审查**：5 个子 agent 分区（AI 面板 / 账号与向导 / 插件与工具 / 数据与设置 / 文案与术语），
   在预览服务（`127.0.0.1:9311`，真实 `dist` 产物）上用 headless Chrome 实拍 1440×900 与 390×844，
   逐页记录「现象 + file:line 证据 + 建议改法」。
2. **统一定义**（Lead 定稿，所有修复遵循）：
   - 术语：账号（不用 Agent/Bot）、功能插件（不用模块）、人格 / 人格预设、模型服务（服务商连接）
     vs 模型（具体模型）、上下文 / 聊天记录 / 会话、配置包（zip）、允许 / 禁止。
   - 一个配置键只有一个编辑入口；覆盖层（账号专属规则 / 单群规则）必须显式说明「会覆盖默认值」。
   - 保存方式要么自动保存（只显示状态），要么手动（只有一个保存按钮），同一屏不得两种并存。
   - 危险操作统一 `ConfirmDialog` + 影响清单。
3. **修复分域并行**：每个子 agent 只改自己的文件域，共享组件（`SaveStatusBar` / `ConfirmDialog`）
   由 Lead 先落地，避免重复实现与互相覆盖。
4. **验收**：`vue-tsc` + 构建 + 文案/结构闸门 + 关键页截图复核 + 新一轮子 agent 交叉审查。
