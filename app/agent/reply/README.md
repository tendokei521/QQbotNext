# `app/agent/reply/` —— 回复观察：判断"这条消息是不是在跟我说"。

## 包含

- `observer.py`：从事件里判断"是否在回应机器人"（回复了机器人、被 @、被叫名字等），
  供参与度成本门与提示词使用；
- `__init__.py`：对外只暴露判断函数，不暴露内部实现。

## 不放

- 不做发送（发送在 `delivery/`）；
- 不决定参与度档位（规则在 `participation.py`，本包只回答"是不是在回应我"）；
- 不解析消息格式（`message_assembly/` 负责）。
